予備×司法書士 肢トレ v002（予備 令和8〜4年度＋司法書士 令和8年度）

■ これは別アプリです
予備試験版のリポジトリとは別に、新しいGitHubリポジトリ（例：shiho-yobi-pwa）を作ってアップしてください。
学習記録も別になります（予備版の記録とは混ざりません）。

- icons/ （icon-180.png, icon-192.png, icon-512.png）
- data/ （R08.js〜R01.js・H30.js・H29.js = 予備試験 令和8年〜平成30年度。民法・商法を含む（令和3年度の民法・商法のみ未収録）／S08.js〜S01.js = 司法書士 令和8〜平成31（令和元）年度）

■ 司法書士データの追加
data フォルダに S08.js, S07.js … （S+令和年2桁）を置くだけで自動で読み込まれます。
予備試験は R+年2桁.js。index.html の変更は不要。反映されない時は app-sw.js の VERSION の数字を上げる。

■ 出題
- 総合ランダム：科目を重み付きで選んでから肢を選びます。
  主要科目（憲法・行政法・民訴・刑法・刑訴・不登法・商登法）は同率、民法・商法は1.5倍（予備・書士の両方を含むため）、
  マイナー科目（民事執行法・民事保全法・供託法・司法書士法）は1/10。
- 弱点優先ON：間違えた肢は3倍、未回答は2倍、正解済みは1倍で出やすくなります。
- 「科目別の成績を見る」で、科目ごとの累積正答率と直近7日の正答率を確認できます。

■ 注意
- 正誤は出題当時の解答から展開したデータです。現行法（令和8年11月時点）との照合は data/P01.js のパッチで反映（⚠法改正メモ）。照合は分野別のキーワード抽出による点検で、全肢の通読ではありません。
- 無料のGitHub Pagesは公開リポジトリが前提です。


【頻出・重要論点モード（v009）】
・data/T01.js が、同じ論点とみなせる肢をグループ化して出題回数（試験の回数）を集計したデータです。
  2回以上＝★重要、3回以上＝★★頻出。出題モードで「重要・頻出論点のみ」「頻出論点のみ」を選べます。
・出題回数が多い論点ほど出やすくなります（2回=1、3回=2、4回=3…の重み）。
・出題画面に★の表示、解答後に「過去N回出題（年度）」を表示。成績画面に頻出・重要・その他の正答率を表示します。
・年度データ(R/S/H*.js)を追加したら、T01.jsは再生成が必要です（Claudeに年度を渡せば一緒に更新されます）。
・手形・小切手など現在ほぼ出題されない論点は回数0扱い（重要・頻出から除外）です。

【v011 追加】
・トップの「頻出・重要論点の一覧を見る」：出題回数の多い順に論点を表示。タップするとその論点の肢だけを出題。正答率60%未満の論点には⚠弱点の印。
・「弱点優先」オン時、頻出・重要モードでは正答率の低い論点（2回以上回答して60%未満）が2倍、未回答の論点が1.3倍出やすくなります。
